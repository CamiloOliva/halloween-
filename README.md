# Noctilucia · La noche que la luna te eligió

Una aventura de Halloween y cumpleaños para **Nailyn**, firmada por **Tu pequeño cuchurrumin**.

## Jugar

**[Abrir la aventura](https://CamiloOliva.github.io/halloween-/)**

El enlace estará disponible cuando GitHub Pages termine la primera publicación. La experiencia se abre directamente en el navegador, sin descargar archivos ni instalar nada.

Activa **Sonido** en la esquina superior derecha para escuchar la música original de caja musical. La aventura dura aproximadamente 5–10 minutos, tiene pistas en cada capítulo y no tiene límite de tiempo.

## La aventura

Tres fragmentos de una estrella se han perdido en Noctilucia. Acompañada por Lúmen, un pequeño fantasma, Nailyn visita un bosque encantado, prepara una poción de deseos y dibuja una constelación. Al final la esperan un pastel, tres velas, una carta y un recuerdo descargable.

- Interacciones con ratón, pantalla táctil y teclado.
- Progreso guardado automáticamente en cada navegador.
- Compatibilidad con la preferencia de movimiento reducido.
- Ilustración original, tipografías locales y música con Web Audio.
- Sin dependencias de ejecución, cuentas de jugador ni servicios de seguimiento.

El deseo se guarda únicamente en el navegador y no se incluye en la imagen descargable.

## Editar

La web usa HTML, CSS y JavaScript. `index.html` es la página de inicio; `styles.css` contiene el diseño; `app.js` contiene la aventura. Puedes modificar el nombre, la firma y la carta final en **`config.js`**. Usa `\n\n` para separar párrafos.

Para probarla localmente, abre `index.html` conservando la carpeta `assets` junto a los demás archivos, o utiliza cualquier servidor estático.

## GitHub Pages

La publicación se configura desde la rama **main**, carpeta **/ (root)**. Los cambios enviados a esa rama se publican automáticamente. El archivo `.nojekyll` permite servir los recursos estáticos directamente.

## Recursos y comprobaciones

La ilustración fue generada para este regalo. Su dirección artística y prompt están en `ART-DIRECTION.md`. Las licencias OFL de Cormorant Garamond y DM Sans están en `assets/fonts/`.

Antes de preparar esta publicación, las pruebas automáticas verificaron una partida completa, la recarga a mitad del juego, los intentos incorrectos, la carta, las velas, la descarga, el reinicio y el funcionamiento sin almacenamiento disponible. No se pudo hacer la revisión visual y de sonido en Brave por los permisos de la herramienta de navegador.
